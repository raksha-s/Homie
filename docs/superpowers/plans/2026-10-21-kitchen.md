# Kitchen Implementation Plan

**Goal:** Foods list, a free meal planner with variety rules, review and publish to My Tasks (PLAN.md Phase 5), with optional free Gemini suggestions on top.

**Architecture:** `kitchen/planner.ts` is a pure rule engine (`generatePlan`, `checkPlan`) that always works and costs nothing. `KitchenProvider` stores foods and published plans in Supabase and publishes meals as routine tasks. No schema change: Light/Heavy is stored as a `heavy` tag in `foods.preferences`. A second step adds Gemini (free tier, user's own key in this browser only); its suggestion is verified by `checkPlan` and falls back to the engine.

## Rules (agreed with the user)
- Light dish: at most 2 days in a row. Heavy dish: never on back-to-back days.
- Nothing except a daily essential or fruit is on more than 2 days of a week.
- Fruit every day; dishes only in allowed meals; reuse a dish for 2 meals a day; long dishes on weekends; weights nutrition 50 / likability 20 / effort 30.
- Too few dishes: still plan, and say which rule had to bend.
- Plan runs from now to Saturday night; meals already past today are left out.
- Publish: routine tasks at 7:00 / 12:00 / 17:00 / 20:00, replacing earlier meal tasks for the same days.

## Tasks
1. Planner + tests (done): `planner.ts`, `window.ts`, `kitchen.test.ts` (example from the brief, full week, shuffle, partial week, rule breaches).
2. Provider + screens (done): foods CRUD, meal picker, review with dropdown swaps, publish, published plan view.
3. Gemini layer: `ai.ts`, key stored in this browser only, verified by `checkPlan`, fallback to the engine.
